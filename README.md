# JobQue.ai Frontend Prototype

This is a responsive frontend prototype for JobQue.ai.

## Pages

- Homepage
- Job dashboard
- Saved profile
- Job alerts
- Application review

## Sponsor feedback updates

- Added smooth page and card animations
- Added animated dashboard numbers and chart bars
- Added a personal greeting and a next-step recommendation
- Added clearer success, error, and button feedback
- Improved keyboard focus and reduced-motion support
- Improved tracker form validation and safer content handling

## Run the website

Open `index.html` in a browser. No installation is required.

This version is a frontend demonstration. Database, API, authentication, automated testing, and full browser-extension connections are future work.
